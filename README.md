**《文明6》的模组管理器**

> 一个强大的现代化模组管理器，帮你在**主菜单**和**对局内**轻松管理模组。

## 它能做什么？

- 收藏/置顶你喜欢的模组，给模组添加备注名。
- 对局内也能管理、启用/禁用模组，无需返回主菜单操作。主菜单和对局内数据互通。
- 搜索模组名称、作者、备注名、订阅 ID，快速找到模组。
- 创建游戏界面、保存/加载界面也能直接进入管理器。
- 新建各种分组并将模组放进去，然后只显示你想看到的分组。
- 通过多种筛选条件，只显示你想看到的模组。
- 支持按作者分组，支持多种排序方式。
- 直接在游戏中退订任意模组。
- 支持多人游戏。
- 支持简中、繁中、英语、日语、韩语、俄语。

## 注意这些！

- **首次启用管理器后，必须重启游戏才能生效。** 禁用管理器后，再次启用它也需要重启游戏。
- 对局内可通过**暂停菜单**进入管理器。也能通过保存/加载界面进入管理器。
- 对局内启用/禁用模组需要重载存档才能生效。模组影响存档时，改动仅在**主菜单**创建新游戏时生效。
- 本管理器不影响游戏平衡。
- 多人对局内无法启用/禁用模组。

## 订阅和使用

- 在 Steam《文明6》创意工坊搜索：[AWAW 模组管理器](https://steamcommunity.com/sharedfiles/filedetails/?id=3832160137)，点赞并订阅模组。
- 在游戏里「附加内容 → 模组」勾选 **AWAW 模组管理器**，然后**重启游戏**。
