**시드 마이어의 문명 6 모드 매니저**

> 메인 메뉴와 게임 안에서 모드를 쉽게 관리할 수 있는 강력하고 현대적인 모드 매니저입니다!

## 할 수 있는 일

- 마음에 드는 모드를 즐겨찾기로 등록해 목록 맨 위에 표시하고, 모드에 별명을 붙일 수 있습니다.
- 게임 중에도 모드를 관리하고 활성화/비활성화할 수 있으며, 메인 메뉴로 돌아갈 필요가 없습니다. 메인 메뉴와 게임 안의 데이터는 공유됩니다.
- 모드 이름, 만든 이, 별명, 구독 ID로 검색해 모드를 빠르게 찾을 수 있습니다.
- 게임 만들기 화면과 저장/불러오기 화면에서도 매니저를 열 수 있습니다.
- 원하는 만큼 그룹을 만들어 모드를 넣고, 보고 싶은 그룹만 표시할 수 있습니다.
- 다양한 필터로 보고 싶은 모드만 표시할 수 있습니다.
- 만든 이별 그룹과 여러 가지 정렬 방식을 지원합니다.
- 게임 안에서 바로 원하는 모드의 구독을 취소할 수 있습니다.
- 멀티 플레이를 지원합니다.
- 중국어 간체, 중국어 번체, 영어, 일본어, 한국어, 러시아어를 지원합니다.

## 주의 사항

- **매니저를 처음 활성화한 뒤에는 게임을 다시 시작해야 적용됩니다.** 비활성화한 뒤 다시 활성화할 때도 재시작이 필요합니다.
- 게임 중에는 **일시정지 메뉴**에서 매니저로 들어갈 수 있습니다. 저장/불러오기 화면에서도 매니저를 열 수 있습니다.
- 게임 중 모드를 활성화 / 비활성화한 변경 사항은 저장 파일을 다시 불러와야 적용됩니다. 저장된 게임에 영향을 주는 모드는 **메인 메뉴**에서 새 게임을 시작할 때만 변경 사항이 적용됩니다.
- 이 매니저는 게임 밸런스에 영향을 주지 않습니다.
- 멀티 플레이 게임에서는 모드를 활성화/비활성화할 수 없습니다.

## 구독 및 사용

- Steam '문명 6' 창작마당에서 [AWAW 모드 매니저](https://steamcommunity.com/sharedfiles/filedetails/?id=3832160137)를 검색하고 좋아요를 누른 뒤 구독해 주세요.
- 게임의 "추가 콘텐츠 → 모드"에서 **AWAW 모드 매니저**를 체크한 뒤 **게임을 다시 시작**하세요.
