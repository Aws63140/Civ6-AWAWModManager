**『シド・マイヤーズ シヴィライゼーション VI』の MOD マネージャー**

> メインメニューでもゲーム中でも、MODの管理が快適になるパワフルでモダンなMODマネージャーです！

## できること

- お気に入りのMODを登録して一覧の先頭に表示し、MODに別名を設定できます。
- ゲーム中でもMODを管理し、有効 / 無効の切り替えもできます。メインメニューに戻る必要はありません。メインメニューとゲーム中でデータは共通です。
- MOD名、作者、別名、サブスクリプション ID で検索し、目的のMODをすばやく見つけられます。
- ゲーム作成画面、セーブ / ロード画面からも直接マネージャーを開けます。
- グループをいくつでも作成してMODをまとめ、見たいグループだけを表示できます。
- さまざまなフィルターで、見たいMODだけを表示できます。
- 作者別のグループ表示と、複数の並べ替えに対応しています。
- ゲーム内から直接、任意のMODの登録を解除できます。
- マルチプレイヤーに対応しています。
- 簡体字中国語、繁体字中国語、英語、日本語、韓国語、ロシア語に対応しています。

## 注意事項

- **マネージャーを初めて有効にした後は、反映するためにゲームを再起動する必要があります。** 無効にした後、再度有効にする場合もゲームの再起動が必要です。
- ゲーム中は**ポーズメニュー**からマネージャーを開けます。セーブ / ロード画面からもマネージャーを開けます。
- ゲーム中のMODの有効 / 無効は、セーブデータを再読み込みすると反映されます。セーブデータに影響するMODの変更は、**メインメニュー**から新しいゲームを開始したときにのみ適用されます。
- 本マネージャーはゲームバランスに影響しません。
- マルチプレイヤーゲームでは、MODの有効 / 無効を切り替えられません。

## サブスクライブと使い方

- Steam『Civilization VI』のワークショップで [AWAW MODマネージャー](https://steamcommunity.com/sharedfiles/filedetails/?id=3832160137) を検索し、いいねを押してサブスクライブしてください。
- ゲームの「追加コンテンツ → MOD」で **AWAW MODマネージャー** にチェックを入れて、**ゲームを再起動**してください。
