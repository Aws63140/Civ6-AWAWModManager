**A mod manager for Sid Meier's Civilization VI (Civ6)**

> A powerful, modern mod manager that makes managing mods easy both in the **main menu** and **in-game**!

## What can it do?

- Favorite the mods you like and show them first, and add aliases to mods.
- Manage mods even in-game, including enabling and disabling them, without returning to the main menu. The main menu and the in-game manager share the same data.
- Search mod names, authors, aliases and subscription IDs to find mods quickly.
- You can also open the manager directly from the Create Game screen and the Save / Load screens.
- Create groups, put mods in them, and then show only the groups you want to see.
- Use a range of filters to show only the mods you want to see.
- Group mods by author and sort them in several ways.
- Unsubscribe any mod directly in the game.
- Supports multiplayer games.
- Supports Simplified Chinese, Traditional Chinese, English, Japanese, Korean and Russian.

## Please note!

- **After enabling the manager for the first time, you must restart the game for it to take effect.** If you disable it, enabling it again also requires a restart.
- In-game, you can open the manager from the **pause menu**. You can also open it from the Save / Load screens.
- Enabling or disabling mods in-game takes effect after reloading the save. If a mod affects saved games, the change applies only when you start a new game from the **main menu**.
- This manager does not affect game balance.
- Mods cannot be enabled or disabled in a multiplayer game.

## Subscribe and use

- Search for [AWAW Mod Manager](https://steamcommunity.com/sharedfiles/filedetails/?id=3832160137) in the Steam Workshop for Civilization VI, then like and subscribe to the mod.
- Tick **AWAW Mod Manager** under **Additional Content → Mods** in the game, then **restart the game**.
