**Менеджер модов для Sid Meier's Civilization VI (Civ6)**

> Мощный современный менеджер модов, который упрощает работу с модами в **главном меню** и **во время игры**!

## Что он умеет

- Добавляйте любимые моды в избранное, выводите их в начало списка и давайте модам псевдонимы.
- Управляйте модами даже во время игры, включая включение и отключение, не возвращаясь в главное меню. Данные главного меню и игры общие.
- Ищите моды по названию, автору, псевдониму и ID подписки.
- Также менеджер можно открыть с экрана создания игры и с экранов сохранения и загрузки.
- Создавайте любое количество групп, объединяйте в них моды и показывайте только нужную.
- Используйте наборы фильтров, чтобы видеть только нужные моды.
- Группируйте моды по автору и выбирайте один из нескольких режимов сортировки.
- Отменяйте подписку на любой мод прямо из игры.
- Играйте по сети.
- Поддерживаются упрощенный и традиционный китайский, английский, японский, корейский и русский языки.

## Обратите внимание!

- **После первого включения менеджера необходимо перезапустить игру.** Если отключить менеджер, для повторного включения тоже потребуется перезапуск.
- Во время игры менеджер можно открыть из **меню паузы**. Также его можно открыть с экранов сохранения и загрузки.
- Включение / отключение модов во время игры вступает в силу после повторной загрузки сохранения. Для мода, влияющего на сохранения, изменения применяются только при создании новой игры из **главного меню**.
- Этот менеджер не влияет на баланс игры.
- В сетевой игре нельзя включать и отключать моды.

## Подписка и использование

- Найдите [AWAW Менеджер модов](https://steamcommunity.com/sharedfiles/filedetails/?id=3832160137) в Мастерской Steam для Civilization VI, поставьте «Нравится» и подпишитесь на мод.
- Включите **AWAW Менеджер модов** в разделе «Дополнительный контент → Моды», затем **перезапустите игру**.
