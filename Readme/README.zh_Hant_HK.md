**《文明6》的模組管理器**

> 一個強大的現代化模組管理器，幫你在**主選單**與**對局內**輕鬆管理模組！

## 它能做什麼？

- 收藏/置頂你喜歡的模組，並為模組新增備註名。
- 對局內也能管理、啟用/停用模組，無需返回主選單操作。主選單與對局內資料互通。
- 搜尋模組名稱、作者、備註名、訂閱 ID，快速找到模組。
- 建立遊戲介面、儲存/載入介面也能直接進入管理器。
- 建立各種分組並將模組放入其中，然後只顯示你想看到的分組。
- 透過多種篩選條件，只顯示你想看到的模組。
- 支援依作者分組，並支援多種排序方式。
- 直接在遊戲中退訂任意模組。
- 支援多人遊戲。
- 支援簡中、繁中、英語、日語、韓語、俄語。

## 注意這些！

- **首次啟用管理器後，必須重啟遊戲才能生效。** 停用管理器後，再次啟用它也需要重啟遊戲。
- 對局內可透過**暫停選單**進入管理器。也能從儲存/載入介面進入管理器。
- 對局內啟用/停用模組需要重載存檔才能生效。模組影響存檔時，變更僅在**主選單**建立新遊戲時生效。
- 本管理器不影響遊戲平衡。
- 多人對局內無法啟用/停用模組。

## 訂閱和使用

- 在 Steam《文明6》工作坊搜尋：[AWAW 模組管理器](https://steamcommunity.com/sharedfiles/filedetails/?id=3832160137)，按讚並訂閱模組。
- 在遊戲裡「額外內容 → 模組」勾選 **AWAW 模組管理器**，然後**重啟遊戲**。
